# Support

## Where to get help

- **Reproducible defects and accessibility or privacy problems:** GitHub Issues using the bug report form.
- **Usage questions and workflows:** GitHub Discussions on this repository.
- **Fiscal assumption reports:** GitHub Issues, with verifiable primary sources attached.
- **Security problems:** see [`SECURITY.md`](SECURITY.md), never a public issue.
- **Operational contacts:** [info@mikesoft.it](mailto:info@mikesoft.it).

## Before asking

1. Check the README troubleshooting section.
2. Search existing issues and discussions.
3. Reproduce the problem on the latest deployment at [easypiva.vercel.app](https://easypiva.vercel.app).

## What support covers

This is a free, maintainer-run project. Support covers defects in the latest published build and questions about documented behavior. It does not cover tax advice, personalized fiscal assistance, customized deployments, or consulting work.

The results are indicative estimates and do not constitute tax, legal, or accounting advice. See the disclaimer in the README and the public information page at [easypiva.vercel.app/informativa](https://easypiva.vercel.app/informativa).

## Response expectations

Best effort, usually within a week. Reports without reproduction steps, or fiscal claims without primary sources, may be closed with a request for details.
